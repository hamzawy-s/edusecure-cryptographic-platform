# Security policy

EduSecure is an academic demonstration, not a production service. Do not upload real student information, production credentials, payment data, or sensitive files to a local demo instance.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. If GitHub private vulnerability reporting is enabled for this repository, use its private reporting flow. Otherwise contact the repository owner privately through their GitHub account and include a concise description, affected version/commit, impact, and reproduction steps. Avoid attaching real user data or secrets.

There is no guaranteed response time or coordinated disclosure program at this time. Security fixes and disclosures are handled by the project owner.

## Scope and expectations

The project demonstrates cryptographic controls in a local academic setting. It has no production SLA, incident response service, or promise of security suitability for real educational, financial, or identity data. Local private keys and demo accounts are not safe for deployment.

When reporting an issue, identify the environment and configuration, distinguish confirmed behavior from speculation, and allow the maintainer reasonable time to investigate before public disclosure.
